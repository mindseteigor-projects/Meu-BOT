# IG Sites CRM — versão 0.1

Protótipo local de CRM comercial para a IG Sites, feito com HTML, CSS e JavaScript puro.

## O que está incluído

- Dashboard com indicadores.
- Cadastro e pesquisa de clientes.
- Alteração da etapa do funil.
- Catálogo inicial de serviços.
- Relatórios demonstrativos e exportação CSV.
- Dados de exemplo fictícios.
- Persistência local via `localStorage`.

## Como executar no VS Code

1. Extraia a pasta `ig-sites-crm`.
2. Abra o VS Code.
3. Selecione **File > Open Folder** (Arquivo > Abrir Pasta) e escolha `ig-sites-crm`.
4. Abra `index.html`.
5. Para uma experiência melhor, instale a extensão **Live Server** no VS Code (opcional).
6. Clique com o botão direito em `index.html` e escolha **Open with Live Server**.

Também é possível abrir `index.html` diretamente no navegador, embora usar um servidor local seja recomendado durante o desenvolvimento.

## Avisos

- Este é um protótipo de interface, não um CRM de produção.
- Os registros são guardados apenas no armazenamento local do navegador utilizado. Não há sincronização entre dispositivos.
- Não cadastre dados reais de clientes nesta versão.
- WhatsApp, IA, autenticação, backend e banco remoto ainda não estão conectados.
- O protótipo não envia mensagens e não acessa contas externas.
